# Prototype V1 — Relationship Presence

This is the first polished browser prototype of **All I Need Is Love**.

## Run

Open `index.html` in a browser. The prototype has no build step and performs no real device access.

Files:
- `index.html` — product screens and content,
- `styles.css` — V1 visual system,
- `app.js` — navigation, mode selection, temporary-session simulation and privacy-state interactions.

## Main navigation

1. **Right Now** — ambient relationship home.
2. **Together** — invite each other into realtime moments.
3. **Our Story** — private shared history.
4. **Us** — pair identity, plans and user-owned controls.

## Core test flow

`Welcome -> Invite -> Mutual connection -> Right Now -> Come Sit With Me -> Accept/Decline -> Together Now -> Our Story -> Your Controls -> Private Time -> Disconnect`

## Research instruction

Do not explain the app before the participant uses it.

Watch for whether they independently understand:
- this is built for two adults living apart,
- each person owns their own settings,
- an invitation is not automatic access,
- realtime interaction begins only after acceptance,
- Private Time is ordinary and unilateral,
- disconnect ends relationship-scoped access,
- the emotional benefit is shared life rather than surveillance.

## Prototype limitations

The current build deliberately has no:
- real account system,
- database,
- device permissions,
- real location,
- camera,
- microphone,
- screen capture,
- push notifications,
- billing,
- analytics.

Those are production concerns and enter only through the gated vertical-slice roadmap.
